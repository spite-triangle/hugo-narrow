# 改进

- 文章添加 `section` 展示，且支持 `left` 展示

    ```yaml
    toc:
      enabled: true # Enable or disable TOC globally
      position: "left" # Options: center | side | left 
    ```
- 修复 `latex` 复杂展示问题
- `posts` 界面列表增加 `section` 展示
- 添加 `term` 终端效果支持
- 数字序号去掉圆形底圈
